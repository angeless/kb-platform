## 一、当前代码现状理解

### update_node()（architecture_service.py:170-191）
- 接收 `node_data` dict，逐字段 setattr 更新节点
- 如果 `node_data` 包含 `parent_id`，直接设置，**无任何校验**
- 没有自引用检查，没有祖先链遍历，没有循环检测
- 问题：可以把节点的 parent_id 设为自身或其后代节点，形成循环

### ErrorCode（codes.py）
- Architecture 区域已有 ARCH_NOT_FOUND, ARCH_NODE_NOT_FOUND, ARCH_ALREADY_PUBLISHED
- 缺少 ARCH_CYCLE_DETECTED

---

## 二、本轮实施计划

1. 在 `codes.py` 的 Architecture 区域新增 `ARCH_CYCLE_DETECTED` 错误码
2. 在 `update_node()` 中，当 `node_data` 包含 `parent_id` 且值不为 None 时：
   - 检查 `parent_id != node_id`（自引用）
   - 从 `parent_id` 开始沿 parent_id 链向上遍历
   - 如果遍历中遇到 `node_id`，抛出 ConflictException(ARCH_CYCLE_DETECTED)
   - 最大遍历深度 50，超过也视为异常
3. 编写测试验证循环检测逻辑

## 四、实现约束

1. 不修改 create_node()（创建时可以通过 parent_id 参数设置父节点，但 PRD 只要求 update_node 检测）
2. 不修改 fork/compare/rollback 等方法
3. parent_id=None 表示移到根节点，不需要循环检测
4. 遍历使用同一个 architecture_id 内的节点
5. 最大深度 50，防止数据异常导致无限循环
