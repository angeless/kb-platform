## 二、本轮实施计划

### 2.1 新增 error-boundary.tsx

1. 创建 React class component（Error Boundary 必须是 class component）
2. 实现 `getDerivedStateFromError` 捕获错误
3. 实现 `componentDidCatch` 记录错误到 console.error
4. 错误状态显示友好页面：
   - 标题："页面出现错误"
   - 说明："请刷新重试"
   - "刷新页面"按钮（调用 `window.location.reload()`）
5. 标记为 `"use client"` 组件

### 2.2 修改 layout.tsx

在 `<Providers>` 内部、`{children}` 外部包裹 `<ErrorBoundary>`。

## 四、实现约束

1. Error Boundary 必须是 class component（React 不支持 function component 的 error boundary）
2. 只捕获 render 阶段的错误，不捕获事件处理器中的错误
3. 使用 `"use client"` 指令（Next.js 要求客户端组件）
4. 样式使用 Tailwind CSS，与项目现有风格一致
5. 不引入新依赖
