## 2. 本轮实施计划

### 目标
新建 `asr_parser.py`，使用 OpenAI Whisper (本地模型) 从音频中提取文字

### 技术选型
- **openai-whisper** — OpenAI 开源 ASR 模型
- 模型：默认 `base`（140MB，中英文均可），可配置
- 支持格式：MP3, WAV, M4A, FLAC, OGG, WEBM 等（通过 ffmpeg）
- 系统依赖：ffmpeg

### 设计要点
- 音频 bytes → 写入临时文件 → Whisper 转录 → 按时间段分 chunk
- Whisper 返回 segments（含 start/end 时间戳），每个 segment 作为一个 chunk
- tags 中记录音频相关元数据（语言、时长）
- ffmpeg 或 whisper 不可用时优雅降级
