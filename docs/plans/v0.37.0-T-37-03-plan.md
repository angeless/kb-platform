## 一、当前代码现状理解

### 批量端点（docs.py:92-173）
- `batch_review`, `batch_publish`, `batch_reject` 三个 router 端点
- 使用 for 循环遍历 doc_ids，每个操作用 try/except 包裹
- 成功记入 succeeded 列表，失败记入 failed 列表
- **问题**：无 savepoint 隔离。如果某个操作导致 session 污染（如 DB 错误），后续操作可能全部失败

### 修改方式
- 在每个操作前后加入 `async with db.begin_nested()` 作为 savepoint
- 成功：savepoint 自动 commit
- 失败：savepoint 自动 rollback，session 恢复到 savepoint 前状态

---

## 二、本轮实施计划

1. 在三个 batch 端点的 for 循环中，每个 doc_id 操作包裹在 `async with db.begin_nested()` 中
2. 失败时 savepoint 回滚，session 保持可用
3. 编写测试验证部分失败不影响其他操作
