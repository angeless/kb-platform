# v0.26.0 前端批次 2：项目详情 + 资料管理 — 实施计划

## 1. 当前代码现状理解

### 前端已有
- 登录/注册页、主布局（侧边栏+顶栏）、项目列表页
- API 客户端、JWT 认证 store

### 后端可用 API
- `GET /v1/projects/{id}` — 项目详情
- `PATCH /v1/projects/{id}` — 更新项目
- `DELETE /v1/projects/{id}` — 删除项目
- `POST /v1/assets/upload` — 上传文件
- `GET /v1/assets?project_id=` — 资料列表
- `GET /v1/assets/{id}` — 资料详情

---

## 2. 本轮实施计划

### 交付页面
1. **项目详情页** `/projects/[id]` — 项目概览 + 资料/文档/架构入口 Tab
2. **项目设置页** `/projects/[id]/settings` — 修改名称/行业、删除项目
3. **资料列表页** `/projects/[id]/assets` — 列出该项目的资料，带解析状态标签
4. **资料上传组件** — 拖拽上传 + 进度显示 + 类型提示
5. **资料详情页** `/assets/[id]` — 显示解析片段
