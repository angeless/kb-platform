# v0.27.0 前端批次 3：知识架构视图 — 实施计划

## 1. 当前代码现状理解

### 后端已有
- `GET /v1/projects/{pid}/architectures` — 架构列表
- `GET /v1/architectures/{id}` — 架构详情（无节点）
- `POST /v1/architectures/{id}/nodes` — 创建节点
- `PATCH /v1/architectures/{id}/nodes/{nid}` — 更新节点
- `POST /v1/architectures/{id}/publish` — 发布架构

### 缺失 API
- **无 list nodes 端点** — 前端无法获取架构的节点列表

### 前端已有
- 项目详情页有"架构"快速统计卡片（链接占位）

---

## 2. 本轮实施计划

### 后端补充（最小改动）
1. 新增 `GET /v1/architectures/{id}/nodes` — 返回架构的所有节点

### 前端页面
1. **架构列表页** `/projects/[id]/architectures` — 列出项目的架构版本
2. **架构详情页** `/architectures/[id]` — 树视图展示节点 + 新增节点表单
3. **节点详情面板** — 点击节点展开侧面板，可编辑属性

### 树构建算法
- 后端返回扁平节点列表
- 前端用 `parent_id` 递归构建树
- 根节点：`parent_id === null`
