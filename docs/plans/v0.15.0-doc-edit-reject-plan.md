# v0.15.0 文档编辑 + 审核驳回 — 实施计划

## 1. 当前代码现状理解

### 已有能力
- 文档状态流转：draft → reviewing → published
- 版本追溯：KnowledgeDocVersion 记录每次变更
- diff 对比：逐行对比两个版本

### 缺失环节
- **无编辑 API** — 文档内容只能由 AI 生成，人工无法修改
- **无驳回操作** — reviewing 状态不能退回 draft，reviewer 无法打回给 editor

### 需求定义
- PRD 5.2："用户可以看懂每份知识...属于哪个模块，为什么这样归类"
  → 隐含用户需要能修改归类错误的内容
- 评测报告 P1-2 / P1-3

---

## 2. 本轮实施计划

### 目标
1. 新增 `PUT /v1/docs/{id}/content` — 编辑文档内容（创建新版本）
2. 新增 `POST /v1/docs/{id}/reject` — 审核驳回（reviewing → draft）
3. 添加请求 schema：DocUpdateContent, DocRejectRequest
4. 编辑操作会自动创建新 version（不覆盖旧内容）

### 状态流转（更新后）
```
draft ──→ reviewing ──→ published
  ↑            │
  └────────────┘ (reject)
```

### 权限
- 编辑内容：editor 及以上
- 驳回：reviewer 及以上

## 4. 实现约束

1. **编辑创建新版本** — 不覆盖旧 content_md，追加 KnowledgeDocVersion
2. **只有 draft 状态可编辑** — published/reviewing 的文档不能直接编辑
3. **驳回只从 reviewing** — 不能从 published 驳回
4. **驳回需要理由** — reject_reason 必填
