# v0.28.0 前端批次 4：知识文档 — 实施计划

## 1. 当前代码现状理解

### 后端已有 API（13 个端点）
- 文档 CRUD：list, get (含版本+来源), pending list
- 状态流转：review, publish, reject
- 内容编辑：PUT content（创建新版本）
- 批量操作：batch review/publish/reject
- 版本对比：diff
- 节点分配：assign-node

### 前端已有
- 项目详情页有"文档"统计卡片（链接占位）
- StatusBadge 组件可复用

---

## 2. 本轮实施计划

### 交付页面
1. **文档列表页** `/projects/[id]/docs` — 表格+状态筛选+分页
2. **待分配池** `/projects/[id]/docs/pending` — node_id=null 的文档
3. **文档详情页** `/docs/[id]` — Markdown 渲染 + 版本历史 + 来源引用
4. **文档编辑页** `/docs/[id]/edit` — Markdown 编辑器 + 预览切换
5. **版本对比页** `/docs/[id]/diff` — 版本选择 + diff 高亮

### 依赖
- `react-markdown` — Markdown 渲染（需安装）
