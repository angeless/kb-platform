# v0.23.0 图片 OCR 解析器 — 实施计划

## 1. 当前代码现状理解

### 已有能力
- 解析器注册表 `worker/parsers/__init__.py` — `PARSERS` 字典映射 asset_type → parser 模块
- 统一接口：`parse(content: bytes, filename: str) -> list[dict]`
- text_parser（纯文本）和 pdf_parser（PDF 文本提取）已实现
- `parse_asset` Celery 任务已支持从 MinIO 下载 + 调用 parser + 写入 chunks

### 缺失环节
- 图片文件（image 类型）上传后标记为 "unsupported"，无法提取文字
- 无 OCR 能力

### 解析器架构
- 每个 parser 是独立 `.py` 模块
- 暴露 `parse(content: bytes, filename: str) -> list[dict]`
- 返回 `[{content_text, page_or_timestamp, tags}]`
- 新增 parser 只需：写模块 + 在 `__init__.py` 注册

---

## 2. 本轮实施计划

### 目标
新建 `ocr_parser.py`，使用 Tesseract OCR（via pytesseract）从图片中提取文字

### 技术选型
- **pytesseract** — Python 封装 Tesseract OCR 引擎
- **Pillow** — 图片读取
- 支持格式：PNG, JPG, JPEG, BMP, TIFF, WEBP
- 中英文支持：Tesseract `chi_sim+eng` 语言包

### 设计要点
- 图片 → Pillow 打开 → pytesseract 提取文字 → 按段落分 chunk
- 如果文字太少（<10 字符），标记为空图片
- tags 中记录 image 相关元数据
