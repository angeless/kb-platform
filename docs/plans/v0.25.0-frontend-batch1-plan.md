# v0.25.0 前端批次 1：壳 + 认证 — 实施计划

## 1. 当前代码现状理解

### 后端已有能力
- `POST /v1/auth/register` — 注册（创建租户+管理员）
- `POST /v1/auth/login` — 登录，返回 JWT
- `GET /v1/projects` — 项目列表（需 JWT）
- 所有 API 返回统一格式 `{data, meta}` 或 `{error_code, message}`

### 前端现状
- **不存在** — 无 `apps/` 目录，无任何前端代码
- 需要从零搭建 Next.js 项目

---

## 2. 本轮实施计划

### 技术选型
| 项 | 选择 | 理由 |
|---|------|------|
| 框架 | Next.js 15 (App Router) | React 最新，SSR/CSR 灵活 |
| UI 库 | shadcn/ui + Tailwind CSS | 轻量、可定制、不引入重依赖 |
| 状态管理 | zustand | 轻量，适合 JWT token 存储 |
| HTTP 客户端 | fetch (native) | Next.js 内置，无需 axios |
| 表单 | react-hook-form + zod | 类型安全的表单校验 |
| 语言 | TypeScript | 类型安全 |

### 交付页面
1. **主布局** — 侧边栏（可折叠）+ 顶栏（用户信息）+ 内容区
2. **登录页** `/login` — 邮箱+密码，调用 `/v1/auth/login`
3. **注册页** `/register` — 租户名+邮箱+密码，调用 `/v1/auth/register`
4. **路由守卫** — 未登录重定向到 `/login`
5. **项目列表页** `/projects` — 登录后首页，列出项目（作为登录成功的验证）

### 设计原则
- 中文 UI，符合知识管理平台的专业感
- 响应式布局，支持桌面和平板
- 错误信息直接显示后端返回的中文 message

## 4. 实现约束

1. **不修改任何后端代码** — 纯前端任务
2. **API 地址可配置** — 通过 `NEXT_PUBLIC_API_URL` 环境变量
3. **不引入多余依赖** — shadcn/ui 按需安装组件，不全量引入
4. **JWT 存 localStorage** — 本阶段简化处理，后续可改 httpOnly cookie
5. **不做 SSR 数据获取** — 认证页面全部 CSR（客户端渲染）
