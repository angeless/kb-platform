# v0.21.0 文档导出功能 — 实施计划

## 1. 当前代码现状理解

### 已有能力
- 文档内容存储为 Markdown（content_md 字段）
- 版本化存储（KnowledgeDocVersion）
- 来源引用（SourceRef）

### 缺失环节
- 无导出 API — 用户无法批量下载知识文档
- 无法将项目所有文档打包导出

---

## 2. 本轮实施计划

### 目标
新增 2 个导出端点：
1. `GET /v1/docs/{id}/export` — 导出单个文档为 Markdown 文件
2. `GET /v1/projects/{id}/export` — 导出项目所有文档为 ZIP 包

### 导出格式
- 单文档：直接返回 `.md` 文件（Content-Type: text/markdown）
- 项目导出：ZIP 包，内含每个文档的 `.md` 文件，按 doc_type 分目录

### ZIP 目录结构
```
project-name/
├── guide/
│   ├── 文档标题1.md
│   └── 文档标题2.md
├── topic/
│   └── 文档标题3.md
└── index.md          # 目录索引
```

---

## 4. 实现约束

1. **只导出最新版本** — 不导出历史版本
2. **只导出 published 或 draft 文档** — 不过滤，全部导出
3. **ZIP 在内存中构建** — 用 io.BytesIO，不写磁盘
4. **文件名安全处理** — 去除特殊字符，避免路径注入
