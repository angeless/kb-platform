# v0.18.0 注册密码强度校验 — 实施计划

## 1. 当前代码现状理解

### 已有能力
- RegisterRequest.password: min_length=8, max_length=128
- Pydantic 自动校验，不满足返回 422

### 缺失环节
- 无复杂度要求，可使用纯数字或纯字母密码

---

## 2. 本轮实施计划

### 目标
在 RegisterRequest schema 层添加密码强度校验：
- 至少 8 位（已有）
- 至少包含 1 个大写字母
- 至少包含 1 个小写字母
- 至少包含 1 个数字
- 至少包含 1 个特殊字符

### 实现方式
使用 Pydantic `field_validator` 在 `RegisterRequest` 中添加校验逻辑。不通过时返回 422 + 明确的中文提示。
