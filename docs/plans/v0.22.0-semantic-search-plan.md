## 2. 本轮实施计划

### 目标
1. 新增 `DocEmbedding` 模型 — 存储 doc_id + embedding 向量（JSONB）
2. 新增 `POST /v1/docs/{id}/embed` — 为文档生成 embedding
3. 新增 `POST /v1/search/semantic` — 语义检索端点
4. embedding 生成通过 httpx 调用 OpenAI API（可替换 provider）

### 技术方案
- **不依赖 pgvector** — 用 JSONB 存向量，应用层计算余弦相似度
- **理由**：避免对 PostgreSQL 扩展的硬依赖，兼容所有环境
- **权衡**：大数据量时性能不如 pgvector，但对知识库场景（千量级文档）足够

### 余弦相似度
```python
def cosine_similarity(a, b):
    dot = sum(x*y for x, y in zip(a, b))
    norm_a = sum(x*x for x in a) ** 0.5
    norm_b = sum(x*x for x in b) ** 0.5
    return dot / (norm_a * norm_b) if norm_a and norm_b else 0.0
```
