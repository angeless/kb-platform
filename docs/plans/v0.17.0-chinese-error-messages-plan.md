# v0.17.0 错误信息统一为中文 — 实施计划

## 1. 当前代码现状理解

### 已有能力
- 统一错误格式：`{"error_code": "...", "message": "...", "detail": {...}}`
- 错误码体系完善：AUTH_*, PROJECT_*, ASSET_*, DOC_*, JOB_*, CONFLICT_*, MODEL_*, SYSTEM_*
- 全局异常处理器已实现（shared_errors/exceptions.py）

### 问题
- 约 35 条错误 message 为英文（如 "Project not found", "Invalid email or password"）
- 约 5 条已经是中文（如 "只有 draft 状态的文档可以编辑"）
- 混杂导致用户体验不一致
