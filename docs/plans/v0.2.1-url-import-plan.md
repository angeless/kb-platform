## 本轮实施计划

### 目标
实现 `POST /v1/assets/import-url` 端点，接受 URL，抓取内容，存入 MinIO，创建 Asset 记录。包含 SSRF 防护。

### 实现方案
1. 新建 `app/utils/url_fetcher.py` — URL 抓取 + SSRF 防护
2. 修改 `asset_service.py` — 新增 `import_url()` 方法
3. 修改 `assets.py` 路由 — 新增 `POST /v1/assets/import-url` 端点
4. 补充测试

## 实现约束

1. **不破坏已有 65 个测试**
2. **SSRF 防护**（设计文档 5.5）：
   - 仅允许 http/https 协议
   - 禁止私有 IP（10.x, 172.16-31.x, 192.168.x, 127.x, ::1）
   - 限制重定向 ≤3 次
   - 请求超时 30 秒
3. **不修改 shared-models / shared-config**
4. **import_url 创建的 Asset**：asset_type="url", source_url 记录原始 URL
5. **内容存储**：抓取的 HTML/内容存入 MinIO，object_path 格式不变
