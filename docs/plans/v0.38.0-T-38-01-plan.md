## 一、当前代码现状理解

### 1.1 MarkdownView 组件现状

- 文件: `apps/web/src/components/markdown-view.tsx`
- 使用 `react-markdown` v10.1.0 渲染 Markdown
- 当前代码: `<ReactMarkdown>{content}</ReactMarkdown>`
- **无任何 HTML 过滤或 sanitize 插件**
- react-markdown v10 默认不渲染原始 HTML 标签（会被当作文本显示），但：
  - 如果有人将来添加 `rehype-raw` 插件就会暴露 XSS
  - 某些属性注入（如 `[link](javascript:alert(1))`）可能绕过默认保护
  - 防御性编程要求显式 sanitize

### 1.2 前端测试现状

- 已有 Vitest 测试框架: `apps/web/src/__tests__/`
- 无 MarkdownView 组件测试
- 已有 setup.ts 文件

### 1.3 依赖现状

- `react-markdown`: v10.1.0 已安装
- `rehype-sanitize`: 未安装

## 二、本轮实施计划

### 2.1 修改目标

1. 安装 `rehype-sanitize` 依赖
2. 在 `MarkdownView` 组件中添加 `rehypeSanitize` 插件
3. 同时添加 `skipHtml={true}` 作为双重防护
4. 编写单元测试验证 XSS 防护

### 2.2 具体步骤

1. `cd apps/web && npm install rehype-sanitize`
2. 修改 `markdown-view.tsx`:
   - 导入 `rehypeSanitize` from `rehype-sanitize`
   - 添加 `rehypePlugins={[rehypeSanitize]}`
   - 添加 `skipHtml={true}`
3. 编写测试: `apps/web/src/__tests__/components/markdown-view.test.tsx`
