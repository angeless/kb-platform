# 样例行业知识库与架构图说明

## 1. 这份样例的作用
本样例不是业务限制，而是为了让开发理解“知识系统架构”和“知识文档落库”最终长什么样。

## 2. 样例行业
本样例使用“企业内部客服与产品培训知识库”作为演示场景。

## 3. 为什么选这个场景
因为它同时包含：
- 制度与流程；
- FAQ；
- 产品知识；
- 培训材料；
- 冲突与版本更新；
- 多来源证据。

## 4. 样例中包含什么
- 一份知识系统架构说明文档；
- 一份 Mermaid 思维导图；
- 一份知识库目录示例；
- 一份 FAQ 示例文档；
- 一份流程文档示例；
- 一份冲突记录示例。

## 5. 开发需要从样例里看懂什么
- 架构图如何驱动归类；
- 新材料进入后如何判断是新增、补充还是冲突；
- Markdown 文档如何保留来源；
- 发布版文档与草稿版文档如何区分。
