## 完成内容

### A. Redis 滑动窗口速率限制
- 新建 `middleware/rate_limit.py`
- 基于 Redis Sorted Set 的滑动窗口算法
- 租户级限流（JWT 提取 tenant_id）+ IP 限流（未认证请求）
- 通用 API: 100次/分钟，上传: 20次/分钟（可配置）
- 超限返回 429 + `Retry-After` 头
- Redis 不可用时 fail open（不阻塞请求）
- 响应头 `X-RateLimit-Limit` / `X-RateLimit-Remaining`

### B. 架构版本历史
| 端点 | 说明 |
|------|------|
| `POST /v1/architectures/{id}/fork` | 深复制架构+节点，version 自动递增 |
| `GET /v1/architectures/{id}/compare/{other_id}` | 按节点名对比差异（新增/删除/修改） |
| `POST /v1/architectures/{id}/rollback/{target_id}` | 从历史版本 fork 回滚 |

### C. Pipeline Worker（9 阶段编排）
| 阶段 | 模块 | 说明 |
|------|------|------|
| 1-2 | ingestion-worker | 已有（文件下载+解析） |
| 3 | classify.py | 分类：新增/补充/纠错/冲突 |
| 4 | architecture_draft.py | 生成/更新架构草稿 |

- 失败时标记具体阶段，支持重试
