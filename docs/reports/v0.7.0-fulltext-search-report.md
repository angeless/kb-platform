```

Content-Type: application/json
Authorization: Bearer <token>

{
  "project_id": "uuid",
  "query": "退款",
  "page": 1,
  "page_size": 20
}

→ 200 OK
{
  "data": [
    {
      "doc_id": "uuid",
      "title": "客服退款规则",
      "doc_type": "topic",
      "status": "published",
      "node_id": "uuid",
      "snippet": "...7天无理由退货，3-5个工作日到账...",
      "matched_field": "content_md",
      "version": 1,
      "created_at": "..."

  ],
  "meta": { "page": 1, "page_size": 20, "total": 1 }
}
```

## 6. 技术决策说明

| 决策 | 理由 |
|------|------|
| 用 ILIKE 而非 tsvector | tsvector 需中文分词插件，增加部署复杂度；ILIKE 对 Sprint 2 数据量足够 |
| 只实现 /search/text | PRD 的 /search/semantic 和 /search/hybrid 需向量库，设计规格已列为 out-of-scope |
| snippet 提取在应用层 | 比 PostgreSQL ts_headline 更灵活，且不依赖分词 |
