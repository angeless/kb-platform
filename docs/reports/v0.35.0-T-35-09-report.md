## 实现说明

### 文档覆盖范围

1. **deployment-guide.md** (FR-35-10-A)
   - 前置条件检查清单（Docker 版本、端口、磁盘、内存）
   - 完整环境变量配置表（6 组共 25+ 变量）
   - 首次部署 5 步流程（获取代码→配置环境→启动服务→迁移→监控）
   - 配置验证清单（7 项 curl 验证命令 + 深度健康检查示例输出）
   - 5 个常见部署问题排查（API 启动失败、DB/Redis/MinIO 连接、Alembic 迁移）
   - 服务架构图 + 容器列表

2. **runbook.md** (FR-35-10-B)
   - 5 个故障场景（DB 连接失败、Redis 故障、MinIO 故障、应用无响应、磁盘不足）
   - 每个场景包含：症状、诊断命令、解决步骤、影响评估
   - 性能调优建议（API/DB/Celery 三层）
   - JSON 结构化日志查询示例（grep + jq 两种方式）
   - 监控与告警（4 个关键 PromQL 指标、健康检查端点、Grafana 仪表盘）
   - 备份与恢复（PostgreSQL + MinIO）
   - 优雅停机流程说明

3. **upgrade-guide.md** (FR-35-10-C)
   - 版本概要（10 项新增能力 + 不变能力列表）
   - 升级前置条件
   - 新增环境变量（CORS_ORIGINS、LOG_LEVEL）+ 生产环境验证说明
   - 新增依赖（python-json-logger、prometheus-client）
   - 5 步升级流程 + 6 项验证命令
   - 数据库迁移说明（无变更）
   - 回滚步骤 + 回滚注意事项
   - 功能启用顺序表
   - 已知限制

### 编写原则
- 所有命令均基于 `docker-compose.yml` 和 `docker-compose.monitoring.yml` 实际配置
- 环境变量来源于 `packages/shared-config/shared_config/settings.py` 的 Settings 类定义
- 端口号、容器名、镜像名与实际配置一致
- 故障排查步骤可直接复制执行
