## 链路打通情况

```
上传文件 → 创建 Asset(parse_status=pending)
         → 创建 Job(type=ingest, asset_id=xxx)
         → 下发 Celery parse_asset(asset_id, job_id)
         → Worker: 下载文件 → 调用 text_parser → 写入 AssetChunk
         → 更新 Asset(parse_status=parsed) + Job(status=completed)
```

## 解析器设计
- **统一接口**: `parse(content: bytes, filename: str) -> list[dict]`
- **注册表**: `worker/parsers/__init__.py` 的 `PARSERS` 字典映射 asset_type → parser module
- **当前支持**: text（纯文本，按双换行分段）
- **扩展方式**: 添加新 parser 模块 + 注册到 PARSERS 字典
