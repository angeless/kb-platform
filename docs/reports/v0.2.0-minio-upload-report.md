## 功能说明

### 文件上传流程（修改后）
1. 路由层接收 multipart 文件
2. **[新增]** 校验文件扩展名是否在白名单内（不在 → 400 ASSET_TYPE_NOT_ALLOWED）
3. **[新增]** 校验文件大小是否超限（超限 → 400 ASSET_TOO_LARGE）
4. 计算 SHA-256 哈希，检查去重
5. **[新增]** 调用 StorageClient.upload_file() 上传到 MinIO
6. **[修改]** 生成真实 object_path：`{tenant_id}/{project_id}/{asset_id}/{filename}`
7. 创建 Asset 数据库记录

### 文件类型白名单
- image: .jpg, .jpeg, .png, .gif, .bmp, .webp, .svg
- audio: .mp3, .wav, .m4a, .flac, .ogg, .aac
- video: .mp4, .mov, .avi, .mkv, .webm
- pdf: .pdf
- doc: .doc, .docx, .xls, .xlsx, .ppt, .pptx
- zip: .zip, .tar, .gz, .7z, .rar
- text: .txt, .md, .csv, .json, .xml, .html, .htm

### 设计决策
- StorageClient 通过 FastAPI 依赖注入，测试中可 mock 为 None
- storage=None 时跳过 MinIO 上传（向后兼容，不破坏已有测试）
- 生产环境首次调用时自动创建 bucket（ensure_bucket）
