## 数据 / API / 状态影响

- **API**: 无变更
- **前端**: 无变更

## 实现说明
1. 在 migration `b2c3d4e5f6a7` 的 `upgrade()` 开头添加 `CREATE TABLE IF NOT EXISTS doc_embedding(...)` 语句
2. 表结构与 `DocEmbedding` ORM 模型完全一致：
   - `id` UUID PK
   - `doc_id` UUID NOT NULL UNIQUE → knowledge_doc.id ON DELETE CASCADE
   - `project_id` UUID NOT NULL → project.id
   - `version` INTEGER NOT NULL
   - `embedding` JSONB NOT NULL
   - `model_name` VARCHAR(100) NOT NULL
   - `dimensions` INTEGER NOT NULL
   - `created_at` / `updated_at` TIMESTAMPTZ NOT NULL DEFAULT now()
3. 同时创建索引 `ix_doc_embedding_project` ON (project_id)
4. `downgrade()` 添加 DROP INDEX + DROP TABLE（在原有 drop_column 之后）
5. 所有 DDL 使用 `IF NOT EXISTS` / `IF EXISTS` 确保幂等
