## 1. 任务编号与目标

**T-37-05**: 空或纯空白查询返回空结果，不执行数据库查询。

## 2. 文件清单

| 文件 | 修改类型 | 说明 |
|------|---------|------|
| `services/api/app/services/search_service.py` | 修改 | `text_search()` 入口增加 strip + 空判断 |
| `services/api/tests/test_search.py` | 修改 | 新增 2 个 API 级测试用例 |
| `services/api/tests/test_search_utils.py` | 修改 | 新增 2 个单元测试用例 |

## 3. 数据/API 影响

- **数据库变更**: 无
- **API 变更**: 无（行为修正，不改接口契约）
- **行为变更**: 全空白查询（如 `"   "`、`"\t\n"`）从返回 ILIKE 意外结果变为返回空结果 (200, total=0, data=[])

## 4. 实现说明

在 `SearchService.text_search()` 方法中（第 82-84 行），在 `_verify_project()` 之后、`_build_tsquery()` 之前：
1. 对 `query` 执行 `strip()` 去除首尾空白
2. 如果 strip 后为空字符串，直接返回 `([], 0)`，不执行任何数据库查询

修改共 2 行代码（+ 1 行空行），最小改动。
