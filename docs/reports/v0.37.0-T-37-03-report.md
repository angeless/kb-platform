## 数据 / API / 状态影响
- **API**: 无变更（路径、参数、返回结构不变）
- **行为变更**: 批量操作中单个失败不再污染 session，后续操作可正常继续
- **数据库**: 无变更
- **前端**: 无变更

## 实现说明

### 修改前
```python
for doc_id in body.doc_ids:
    try:
        doc = await svc.review(doc_id)
        await audit.log(...)
        succeeded.append(doc_id)
    except Exception as e:
        failed.append(...)
```

### 修改后
```python
for doc_id in body.doc_ids:
    try:
        async with db.begin_nested():
            doc = await svc.review(doc_id)
            await audit.log(...)
        succeeded.append(doc_id)
    except Exception as e:
        failed.append(...)
```

三个端点（batch_review, batch_publish, batch_reject）均做相同修改。
