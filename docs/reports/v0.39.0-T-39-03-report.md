## 3. 数据 / API 影响

## 4. 实现说明

### 排除规则

| 排除项 | 原因 |
|--------|------|
| `.git` | 版本控制数据，构建不需要 |
| `.env` / `.env.*` | 防止敏感配置泄露 |
| `!.env.example` | 取反保留，ingestion-worker 和 ai-orchestrator 需要 |
| `node_modules` / `apps/web/.next` | 前端依赖和构建产物 |
| `__pycache__` / `*.pyc` / `.pytest_cache` | Python 缓存文件 |
| `.DS_Store` | macOS 系统文件 |
| `docs/` | 文档目录 |
| `*.md` / `!README.md` | Markdown 文件（保留 README） |
| `.github` / `.claude` | CI/CD 配置和工具配置 |
| `SECURITY_*` | 安全审计报告 |
| `docker-compose*.yml` | 编排文件不需要进入容器 |

### 必要路径验证

逐一核对 4 个 Dockerfile 的所有 COPY 路径（`packages/`、`services/*`、`.env.example`、`infra/sql/`、`infra/docker/api-entrypoint.sh`），确认均未被排除。

## 6. 影响分析

- **构建优化**：构建上下文不再包含 `.git`（通常数百 MB）、`node_modules`、文档等无关文件
- **安全加固**：`.env` 文件不会意外进入镜像
- **无破坏性**：不修改任何 Dockerfile，不影响构建逻辑
