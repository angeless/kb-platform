- **日期**: 2026-03-18

## 问题描述
用户上传 image/audio/video 等暂不支持解析的文件后，parse_status 显示 "pending"，用户误以为系统正在处理，实际上这些类型没有解析器，任务会失败。

## 完成内容

### 行为变更
| 文件类型 | 上传后 parse_status | 说明 |
|---------|-------------------|------|
| .txt / .md / .csv / .json 等 | **pending** | 可解析，等待 ingestion-worker 处理 |
| .pdf | **pending** | 可解析，PdfParser 处理 |
| .doc / .docx 等 | **pending** | 可解析，走 PDF 解析管道 |
| .jpg / .png / .mp3 / .mp4 等 | **unsupported** | 文件已存储，但暂不支持自动解析 |

### Bug 修复
- **PARSERS 注册表命名不一致**: `guess_asset_type()` 返回 `"doc"`，但注册表用 `"document"` → .docx 文件无法匹配解析器。已修复为统一使用 `"doc"`
- **parse_asset 失败处理**: 无解析器时从 raise ValueError（标记 failed）改为标记 unsupported 并正常完成 job
