## 数据 / API / 状态影响
- **API**: 无变更（路径、参数、返回结构不变）
- **行为变更**: update_node() 当 parent_id 变更时：

  - 祖先链中存在 node_id → ConflictException(ARCH_CYCLE_DETECTED, "修改父节点会形成循环引用")
  - 最大遍历深度 50
- **数据库**: 无变更

### 修改后
```python
async def update_node(self, arch_id, node_id, node_data):
    # ... 查找节点 ...
    new_parent_id = node_data.get("parent_id")
    if new_parent_id is not None:
        if new_parent_id == node_id:
            raise ConflictException(ARCH_CYCLE_DETECTED, "节点不能将自身设为父节点")
        current_id = new_parent_id
        for _ in range(50):
            parent_node = query(current_id, arch_id)
            if parent_node is None or parent_node.parent_id is None:
                break
            if parent_node.parent_id == node_id:
                raise ConflictException(ARCH_CYCLE_DETECTED, "修改父节点会形成循环引用")
            current_id = parent_node.parent_id
    for key, value in node_data.items():
        if value is not None:
            setattr(node, key, value)
    await self.db.flush()
```
