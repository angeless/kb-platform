## 实现说明

### 修改前（rate_limit.py:57-61）
```python
payload = jwt.decode(
    auth[7:], settings.jwt_secret,
    algorithms=[settings.jwt_algorithm],
    options={"verify_exp": False},  # ← 不验证过期
)
```

### 修改后
```python
payload = jwt.decode(
    auth[7:], settings.jwt_secret,
    algorithms=[settings.jwt_algorithm],
    # verify_exp defaults to True — expired tokens raise ExpiredSignatureError
)
```

### 设计要点
- 只删除了一个选项参数（`options={"verify_exp": False}`）
- `jwt.decode()` 默认 `verify_exp=True`
- 过期 token 抛出 `ExpiredSignatureError`，被已有的 `except Exception: pass` 捕获
- 自动回退到 IP 限流（已有逻辑，无需修改）
