## 2. 问题定义

v0.5.0 完成后，`generate_docs` 任务已正确写入 KnowledgeDoc + KnowledgeDocVersion + SourceRef 记录，但 `GET /v1/docs/{id}` 端点只返回文档元信息（标题、状态），不返回：
- 版本列表（Markdown 正文内容）
- 来源引用（SourceRef，追溯到原始 AssetChunk）

用户无法查看生成的文档内容和来源追溯。

## 3. 完成内容

### 3.1 Schema 增强
- **文件**：`packages/shared-schemas/shared_schemas/knowledge.py`
- 新增 `SourceRefOut` — 来源引用的序列化 schema
- 在 `DocVersionOut` 中添加 `source_refs: list[SourceRefOut]` 字段
- 新增 `KnowledgeDocDetailOut` — 完整文档详情（含 versions + source_refs）

### 3.2 Service 增强
- **文件**：`services/api/app/services/doc_service.py`
- 新增 `get_version(doc_id, version)` 方法 — 获取特定版本

### 3.3 Router 增强
- **文件**：`services/api/app/routers/docs.py`
- `GET /v1/docs/{id}` 改用 `KnowledgeDocDetailOut`，返回完整版本和来源
- 新增 `GET /v1/docs/{id}/versions/{version}` 端点 — 获取特定版本详情

### 3.4 测试增强
- **文件**：`services/api/tests/test_docs.py`
- 更新 fixture：添加 Asset + AssetChunk + SourceRef 数据
- 更新 `test_get_doc_with_versions`：验证返回 versions + content_md + source_refs
- 新增 `test_get_doc_version`：验证获取特定版本
- 新增 `test_get_doc_version_not_found`：验证版本不存在返回 404

## 6. API 变更说明

### 变更前
```
GET /v1/docs/{id} → { id, title, status, doc_type, ... }
```

### 变更后
```
GET /v1/docs/{id} → {
  id, title, status, doc_type, ...,
  versions: [
    {
      version: 1,
      content_md: "# Markdown 正文...",
      source_refs: [
        { asset_chunk_id: "...", location_hint: "page 1" }
      ]
    }
  ]
}

GET /v1/docs/{id}/versions/{version} → {
  version: 1,
  content_md: "...",
  source_refs: [...]
}
```
