## 完成内容

### 新增能力
- 图片（PNG/JPG/BMP/TIFF/WEBP）通过 Tesseract OCR 提取文字
- 支持中英文（chi_sim+eng）
- 文字按段落分 chunk，tags 包含图片尺寸/格式元数据
- Tesseract 不可用时优雅降级（返回空 chunks，不崩溃）
