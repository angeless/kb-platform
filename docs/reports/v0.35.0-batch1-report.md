# v0.35.0 批次一汇报 — 生产就绪基础设施

## 版本信息
- **版本**: v0.35.0（批次一）
- **任务**: T-35-01 ~ T-35-07（7 个任务）
- **日期**: 2026-03-19

## 完成内容

### T-35-01: API 版本端点 + CORS 策略配置
- `GET /api/versions` 端点 — 返回支持的 API 版本列表
- `CORSMiddleware` 配置 — 通过 `CORS_ORIGINS` 环境变量控制允许源
- Settings 新增 `cors_origins` 字段（默认 `http://localhost:3000,http://localhost:3001`）
- 4 个测试用例

### T-35-02: 深度健康检查
- `GET /api/health/ready` 端点 — 并发检查 PostgreSQL、Redis、MinIO 连通性
- 状态聚合逻辑：ok / degraded / unhealthy（503）
- 每项检查 1s 超时
- 5 个测试用例

### T-35-03: 结构化 JSON 日志
- `python-json-logger` v4 集成
- `KBJsonFormatter` 自定义格式器 — 输出 JSON 日志到 stdout
- 支持 `request_id`、`user_id` 额外字段注入
- 4 个测试用例

### T-35-04: Prometheus 指标暴露
- `GET /metrics` 端点 — Prometheus text format
- `MetricsMiddleware` — 自动采集 HTTP 请求指标
- 4 个核心指标：`http_requests_total`、`http_request_duration_seconds`、`http_request_size_bytes`、`http_response_size_bytes`
- UUID 路径归一化（减少 cardinality）
- 3 个测试用例

### T-35-05: Grafana 仪表盘
- `docker-compose.monitoring.yml` — Prometheus + Grafana 服务
- `monitoring/prometheus.yml` — scrape 配置（15s 间隔）
- 3 个预配置仪表盘 JSON：
  - 应用性能（请求速率、错误率、P50/P95/P99 响应时间）
  - 资源利用（请求/响应大小分布、进程内存/CPU）
  - 业务指标（端点级请求速率、上传/搜索/认证活动）
- Grafana 自动数据源 + Dashboard provisioning

### T-35-06: CI/CD Pipeline
- `.github/workflows/ci.yml` — PR 验证流水线
  - pgvector PostgreSQL + Redis 服务容器
  - 5 个测试阶段：非 DB 测试、DB 测试、Ingestion/Pipeline/AI-Orchestrator 测试
  - 前端 Vitest + TypeScript 类型检查
- `.github/workflows/build.yml` — Tag 触发的 Docker 镜像构建
  - GHCR 推送 API + Worker 镜像

### T-35-07: 优雅停机处理
- FastAPI lifespan 上下文管理器 — 启动/关闭 hook
- 关闭时：dispose DB 连接池 + flush 日志缓冲
- `docker-compose.yml`：
  - API: `stop_grace_period: 30s`
  - Workers: `stop_grace_period: 35s` + `--soft-time-limit=25` + `--time-limit=30`
