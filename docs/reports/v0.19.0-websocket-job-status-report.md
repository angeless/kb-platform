## 完成内容

### 新增端点
| 协议 | 路径 | 说明 |
|------|------|------|
| WebSocket | `/v1/ws/jobs/{project_id}?token=xxx` | 实时接收任务状态变更 |

### 事件格式
```json
{
  "event": "job_status_changed",
  "job_id": "uuid",
  "project_id": "uuid",
  "status": "running|completed|failed",
  "job_type": "ingest|architecture_draft|kb_generate|incremental",
  "error_message": null,
  "timestamp": "2026-03-18T12:00:00Z"
}
```

### 架构
```
Worker (status change) → Redis Pub/Sub → API WebSocket → Client
```

### 修改文件
| 文件 | 操作 | 说明 |
|------|------|------|
| `services/api/app/routers/ws.py` | **新建** | WebSocket 端点 + Redis subscribe |
| `services/api/app/main.py` | **修改** | 注册 ws router |
| `services/ingestion-worker/worker/tasks.py` | **修改** | 状态变更时 publish Redis 事件 |
| `services/ai-orchestrator/orchestrator/tasks.py` | **修改** | 状态变更时 publish Redis 事件 |
| `services/api/tests/test_ws.py` | **新建** | 3 个 WebSocket 测试 |

### 设计要点
- **认证**: query param `token` 传 JWT，服务端验证后接受连接
- **非阻塞 publish**: Worker 发布事件失败仅 debug log，不影响任务执行
- **每 project 一个 channel**: `job_events:{project_id}`，隔离不同项目的事件流
