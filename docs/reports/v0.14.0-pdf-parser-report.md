### PDF 解析器特性
- 按页切分（每页一个 chunk）
- 空页自动跳过
- 长页（>5000 字符）按段落二次切分
- page_or_timestamp 记录页码（如 page-1, page-2）
- tags 包含 source_type=pdf, filename, page
- 支持中文 PDF（pymupdf 原生支持）

### 解析器注册
| asset_type | 解析器 |
|-----------|--------|
| text | TextParser |
| pdf | PdfParser |
| document | PdfParser |
