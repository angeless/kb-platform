## 技术决策记录
- JWT 使用 HS256（简化阶段，后续可升 RS256）
- API Key 使用 AES-256-GCM 加密存储
- 多租户隔离通过 tenant_id→project 链路实现
- 知识文档采用版本追加模式（不覆盖）
- 项目删除采用软删除（status="deleted"）
- MinIO 上传暂为 stub（存路径不实际上传）
