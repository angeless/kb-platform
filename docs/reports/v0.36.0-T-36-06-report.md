### 修改后

```python
async def delete(self, user_id: uuid.UUID, operator_id: uuid.UUID | None = None) -> User:
    # Rule 1: cannot delete yourself
    if operator_id is not None and user_id == operator_id:
        raise ForbiddenException(message="不能删除自己的账号")

    # ... find user ...

    # Rule 2: cannot delete the last admin
    if user.role in ("tenant_admin", "admin"):
        admin_count = ... # count active admins in tenant
        if admin_count <= 1:
            raise ConflictException(
                error_code=ErrorCode.AUTH_INSUFFICIENT_ROLE,
                message="不能删除租户唯一管理员",
            )
```

### Router 变更
```python
user = await svc.delete(user_id, operator_id=_user.id)
```

### 设计要点
- `operator_id` 默认 None，保持向后兼容
- 管理员定义：role in ("tenant_admin", "admin") 且 status="active"
- 自删除检查在数据库查询之前（快速失败）
- 唯一管理员检查在找到用户之后、设置 disabled 之前
