## 1. 版本目标

在 v0.34.0（质量提升）基础上，补齐生产环境运行所需的运维可观测性和基础设施能力，使平台达到可部署、可监控、可诊断、可升级的生产就绪状态。

**核心约束**：
- 不涉及数据库 schema 变更
- 不影响现有业务逻辑和 API 契约
- 所有新增能力均可独立启用/禁用

## 10. 升级与回滚

- **升级**：拉取代码 → 可选配置 CORS_ORIGINS → 重建 Docker 镜像 → 重启服务 → 验证
- **回滚**：切回 v0.34.0 代码 → 重建 → 重启，无需数据库回滚
- **详细步骤**：见 `docs/operations/upgrade-guide.md`

---

## 11. 已知限制

1. `/api/health/ready` 每次调用创建临时连接，适合低频探测（≤1次/30秒）
2. Grafana 仪表盘初始密码 `admin/admin`，首次登录后需修改
3. CI/CD 流水线推送镜像需配置 `GHCR_TOKEN` secret
4. OpenAPI 不支持 WebSocket 端点文档化（`/ws/{project_id}` 未增强）
