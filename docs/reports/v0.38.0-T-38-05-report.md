## 4. 实现说明

### 测试修复
T-38-05 任务计划中"修复 3 个失败测试"部分已在 T-38-01 中完成（vitest.config.ts JSX 转换配置 + @testing-library/dom 依赖），无需重复修复。

### Error Boundary
- **ErrorBoundary** class component（React 要求 error boundary 必须是 class component）
- `getDerivedStateFromError()`: 捕获错误，设置 hasError 状态
- `componentDidCatch()`: 记录错误详情到 console.error（含 componentStack）
- 错误页面：居中显示"页面出现错误"+"请刷新重试"+"刷新页面"按钮
- 按钮调用 `window.location.reload()` 刷新页面

### layout.tsx
- ErrorBoundary 包裹在 Providers 内部、children 外部
- 层级：`<Providers><ErrorBoundary>{children}</ErrorBoundary></Providers>`

## 6. 影响分析

- **用户体验提升**：组件 render 错误不再导致白屏，显示友好错误页面
- **可调试性**：错误详情（含 componentStack）记录到 console
- **无破坏性**：ErrorBoundary 透明包裹，正常渲染时不影响任何行为
- **局限性**：只捕获 render 阶段错误，不捕获事件处理器/异步错误（React 限制）
