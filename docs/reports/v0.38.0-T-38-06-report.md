## 4. 实现说明

### dirty 标记
- 使用 `useRef` 保存加载时的原始内容 `initialContentRef`
- `isDirty = content !== initialContentRef.current`
- 保存成功后 `initialContentRef.current = content` 清除 dirty

### beforeunload 拦截
- useEffect 注册 `window.addEventListener("beforeunload", handler)`
- 当 isDirty 时调用 `e.preventDefault()` + `e.returnValue = ""`
- 浏览器显示原生"确认离开"弹窗
- 覆盖场景：关闭标签页、刷新页面、浏览器后退

### SPA 内部导航拦截
- "返回文档"从 `<Link>` 改为 `<button>` + `handleNavigateBack()`
- "取消"从 `<Link>` 改为 `<button>` + `handleNavigateBack()`
- `handleNavigateBack`: isDirty 时 `window.confirm("有未保存的修改，确定离开吗？")`

### 已知限制
- Next.js App Router 不支持 `beforePopState`（Pages Router API）
- 侧边栏 `<Link>` 导航无法通过 beforeunload 拦截（SPA 内部导航不触发页面卸载）
- 这是 Next.js App Router 的已知限制，等官方 Navigation Guard API
