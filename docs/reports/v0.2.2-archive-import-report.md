## 功能说明
- 接受 multipart ZIP 文件 + project_id
- 内存中解压（不写临时文件）
- 逐文件校验扩展名白名单，跳过不支持的类型
- 逐文件检查 SHA-256 去重，跳过重复
- 逐文件调用 `guess_asset_type()` 自动识别类型
- 每个文件独立创建 Asset 记录 + 上传 MinIO
- 返回 `{imported: N, skipped: M, errors: [...]}`
- 限制单包 ≤100 文件（zip bomb 防护）
- 当前仅支持 ZIP 格式
