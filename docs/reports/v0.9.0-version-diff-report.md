### 2.1 Diff Schema
- `DiffLineOut` — 单行差异（type: context/added/removed）
- `DiffStatsOut` — 差异统计（added/removed/unchanged）
- `VersionDiffOut` — 完整比对结果

### 2.2 Diff Service
- `DocService.diff_versions(doc_id, from_version, to_version)` — 使用 `difflib.SequenceMatcher` 计算行级差异

### 2.3 Diff Router
- `GET /v1/docs/{id}/diff?from_version=1&to_version=2` — 版本比对端点
