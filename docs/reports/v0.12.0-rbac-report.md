### 权限矩阵
| 角色 | 级别 | 可执行操作 |
|------|------|-----------|
| viewer | 0 | 所有 GET 查询 |
| editor | 1 | + 上传、创建任务、绑定节点 |
| reviewer | 2 | + 审核文档、解决冲突 |
| project_admin | 3 | + 发布文档、发布/修改架构 |
| tenant_admin / admin | 4 | + 模型配置、用户管理、审计查询、删除项目 |
| platform_admin | 5 | 所有操作 |

### 设计决策
- **角色层级数值比较** — 高级角色自动继承低级权限，无需逐个枚举
- **`admin` 作为 `tenant_admin` 的遗留别名** — 兼容历史数据，避免破坏现有测试
- **GET 端点不加角色限制** — viewer 可查看，保持最低权限原则
- **`require_role()` 返回 `Depends`** — 与 FastAPI 依赖注入完美配合
