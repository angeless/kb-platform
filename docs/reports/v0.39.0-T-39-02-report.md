## 4. 实现说明

### 统一方案

在每个 Dockerfile 中，在所有 `RUN pip install` 和 `COPY` 完成后、`CMD`/`ENTRYPOINT` 之前添加：

```dockerfile
# Run as non-root user
RUN addgroup --system appgroup && adduser --system --ingroup appgroup appuser
USER appuser
```

### 各 Dockerfile 差异处理

| Dockerfile | 特殊处理 |
|-----------|---------|
| api.Dockerfile | USER 在 EXPOSE 后、ENTRYPOINT 前；entrypoint.sh 已在 root 阶段 chmod +x |
| ingestion-worker | USER 在 COPY .env 后、CMD 前 |
| pipeline-worker | USER 在 pip install 后、CMD 前 |
| ai-orchestrator | USER 在 COPY .env 后、CMD 前 |

### 权限说明

- `/app` 和 `/packages` 目录在 root 阶段创建和安装，默认 world-readable
- `adduser --system` 创建系统用户（无 home 目录、无 login shell）
- pip editable install 在 root 阶段完成，运行时不需要写入 .egg-info
- entrypoint.sh 在 root 阶段 `chmod +x`，appuser 可执行
