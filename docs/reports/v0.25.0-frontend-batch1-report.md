### 交付页面
| 页面 | 路径 | 说明 |
|------|------|------|
| 首页重定向 | `/` | 已登录→项目列表，未登录→登录页 |
| 登录页 | `/login` | 邮箱+密码，表单校验，调用 `/v1/auth/login` |
| 注册页 | `/register` | 组织名+邮箱+密码+确认密码，密码强度校验 |
| 项目列表 | `/projects` | 卡片式展示，支持新建项目 |

### 核心组件
| 组件 | 说明 |
|------|------|
| `Sidebar` | 左侧导航栏，8 个模块入口，当前路由高亮 |
| `Topbar` | 顶栏，显示用户邮箱/角色，退出按钮 |
| `DashboardLayout` | 路由守卫，未登录自动跳转 |

### 基础设施
| 文件 | 说明 |
|------|------|
| `lib/api.ts` | API 客户端，统一 auth header 和错误处理 |
| `stores/auth-store.ts` | JWT 存储、登录、注册、登出 |
| `lib/utils.ts` | cn() 工具函数 |
