### 新增端点
| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/v1/search/embed/{doc_id}` | 为文档生成 embedding 向量 |
| POST | `/v1/search/semantic` | 语义检索（余弦相似度排序） |

### 技术方案
- **不依赖 pgvector** — 用 JSONB 存向量，应用层计算余弦相似度
- **embedding 生成** — 默认调用 OpenAI text-embedding-3-small API
- **可替换 provider** — `EmbeddingService(embed_fn=...)` 支持注入自定义 embedding 函数
- **测试中 mock** — 不调外部 API，用固定向量验证流程
