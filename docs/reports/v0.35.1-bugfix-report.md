## 实现说明

### T-FIX-01: TenantService 基类

1. 在 `services/api/app/services/__init__.py` 中创建 `TenantService` 类
2. 基类提供 `db`、`tenant_id` 属性和 `_verify_project(project_id) -> Project` 方法
3. 8 个 service 继承 `TenantService`：
   - **简单继承**（`__init__` 与基类一致）：DocService、ArchitectureService、SearchService、ExportService
   - **扩展初始化**（`super().__init__()` + 额外属性）：AssetService（+user_id, storage, max_upload_size_bytes）、ConflictService（+user_id）、JobService（+user_id）、EmbeddingService（+embed_fn）
4. `export_service.py` 原方法名 `_get_project` 删除后统一使用基类 `_verify_project`，2 处调用点对应更新
5. 清理 7 个文件中不再使用的 `Project` import 和 `select` 引用

### T-FIX-02: 错误消息修复

仅 1 行改动：`doc_service.py:79` 的 `f"Version {version} not found"` → `f"版本 {version} 不存在"`

### 未修改的 service
