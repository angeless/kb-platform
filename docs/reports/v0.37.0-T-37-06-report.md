# T-37-06 任务汇报：SSRF 补充封锁

**任务编号**: T-37-06
**版本**: v0.37.0
**日期**: 2026-03-20
**作者**: Claude Code

---

## 1. 任务编号与目标

**T-37-06**: URL 导入时封锁 0.0.0.0 和 :: 地址，防止 SSRF 绕过。

## 2. 文件清单

| 文件 | 修改类型 | 说明 |
|------|---------|------|
| `services/api/app/utils/url_fetcher.py` | 修改 | `_BLOCKED_NETWORKS` 追加 2 项 |
| `services/api/tests/test_url_fetcher.py` | 新增 | 11 个 `validate_url()` 单元测试 |
| `docs/plans/v0.37.0-T-37-06-plan.md` | 新增 | 实施计划 |

## 3. 数据/API 影响

- **数据库变更**: 无
- **API 变更**: 无（行为修正，不改接口契约）
- **行为变更**: `http://0.0.0.0:*` 和 `http://[::]:*` 的 URL 导入被拒绝（返回 SYSTEM_SSRF_BLOCKED）

## 4. 实现说明

在 `url_fetcher.py` 第 29-30 行，向 `_BLOCKED_NETWORKS` 列表追加：
- `ipaddress.ip_network("0.0.0.0/32")` — 通配地址
- `ipaddress.ip_network("::/128")` — IPv6 未指定地址

修改共 2 行代码。

## 5. 验证结果

### 5.1 单元测试

- `test_url_fetcher.py`: **11 项全部通过**
  - `test_blocks_zero_address`: 0.0.0.0 被封锁 ✅
  - `test_blocks_ipv6_zero_address`: :: 被封锁 ✅
  - `test_blocks_loopback`: 127.0.0.1 回归 ✅
  - `test_blocks_private_10/172/192`: 私有 IP 回归 ✅
  - `test_blocks_ipv6_loopback`: ::1 回归 ✅
  - `test_allows_public_url/ip`: 公网不受影响 ✅
  - `test_blocks_ftp_protocol`: 非法协议仍封锁 ✅
  - `test_blocks_missing_hostname`: 缺主机名仍封锁 ✅

### 5.2 验收标准对照

| 验收标准 | 结果 |
|---------|------|
| 导入 URL `http://0.0.0.0:8080/file.txt` 被拒绝 | ✅ SYSTEM_SSRF_BLOCKED |
| 导入 URL `http://[::]:8080/file.txt` 被拒绝 | ✅ SYSTEM_SSRF_BLOCKED |
| 导入正常公网 URL 不受影响 | ✅ 验证通过 |
| 已有私有 IP 封锁不受影响（回归） | ✅ 验证通过 |

## 6. 影响分析

- **风险**: 极低。仅追加黑名单条目，不改变验证逻辑
- **回归风险**: 无。已有封锁规则不变，新增条目只收紧范围
- **已知限制**: 未做 DNS rebinding 防护（任务计划明确排除，可后续版本处理）
