## 完成内容

### 新增端点
| 方法 | 路径 | 说明 | 最低权限 |
|------|------|------|----------|
| POST | `/v1/docs/batch/review` | 批量审核 | reviewer |
| POST | `/v1/docs/batch/publish` | 批量发布 | project_admin |
| POST | `/v1/docs/batch/reject` | 批量驳回 | reviewer |

### 请求/响应格式
**请求**: `{"doc_ids": ["uuid1", "uuid2", ...]}`（最多 50 条）

**响应**: `{"succeeded": [...], "failed": [{"id": "uuid", "reason": "..."}]}`

### 设计要点
- **部分成功** — 一个失败不阻塞其他
- **复用现有逻辑** — 逐条调用 service 方法，不绕过校验
- **审计覆盖** — 每条成功的操作都写审计日志
- **路由顺序修复** — batch 路由必须在 `/{doc_id}` 之前注册（FastAPI 按顺序匹配）
