**T-38-01**: 知识文档中的 Markdown 渲染不执行嵌入的 HTML/JS，防止 XSS 攻击。

## 3. 数据/API 影响

- **数据库变更**: 无
- **API 变更**: 无
- **前端行为变更**:
  - `<script>` 标签被过滤，不渲染
  - `onerror`/`onclick` 等事件属性被过滤
  - 正常 Markdown（标题、链接、代码块、列表、图片）不受影响

## 4. 实现说明

### 4.1 核心修改（markdown-view.tsx）

```tsx
// 修改前
<ReactMarkdown>{content}</ReactMarkdown>

// 修改后
<ReactMarkdown skipHtml rehypePlugins={[rehypeSanitize]}>{content}</ReactMarkdown>
```

双重防护：
- `skipHtml`: react-markdown 层面忽略原始 HTML
- `rehypeSanitize`: rehype 层面使用 GitHub schema 过滤危险标签和属性

### 4.2 附带修复（vitest 配置）

修复了 vitest 无法运行 JSX 组件测试的已有问题：
- 添加 `esbuild: { jsx: "automatic" }` 支持 React 17+ 自动 JSX 转换
- 安装缺失的 `@testing-library/dom` 依赖
- **此修复使原有 3 个失败的测试恢复通过**
