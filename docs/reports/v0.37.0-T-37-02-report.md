## 实现说明

### 上传顺序
开发计划描述的"先 DB 后 MinIO"顺序问题在当前代码中**不存在**——upload() 和 import_url() 已经是先 MinIO 后 DB。

### 新增功能

1. **StorageClient.delete_file()**（storage.py）
```python
def delete_file(self, object_key: str) -> None:
    try:
        self.client.delete_object(Bucket=self.bucket, Key=object_key)
    except Exception as e:
        logger.warning("Failed to delete %s: %s", object_key, e)
```

2. **upload() flush 清理**（asset_service.py）
```python
try:
    await self.db.flush()
except Exception:
    if self.storage is not None:
        self.storage.delete_file(object_path)
    raise
```

3. **import_url()** 同样增加清理逻辑
