### 设计要点
- **编辑创建新版本** — 不覆盖旧内容，追加 KnowledgeDocVersion，current_version 递增
- **只有 draft 可编辑** — published/reviewing 返回 409
- **驳回需要理由** — reject_reason 记录到审计日志 detail 中
- **审计覆盖** — edit 和 reject 操作均写入审计日志
