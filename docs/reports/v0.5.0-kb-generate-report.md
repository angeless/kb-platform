## 2. 完成内容

### 2.1 新增 Prompt 模板
- **文件**：`services/ai-orchestrator/orchestrator/prompts.py`
- **新增**：`build_generate_doc_prompt()` 函数 + `SYSTEM_PROMPT_GENERATE_DOC` + `USER_PROMPT_GENERATE_DOC_TEMPLATE`
- **设计**：
  - 每个 chunk 带序号标签 `[片段N]`，便于 LLM 引用
  - 要求 LLM 返回 `cited_chunk_indices` 用于 SourceRef 追溯
  - 要求 LLM 检测冲突并返回 `has_conflicts` + `conflict_description`
  - 遵循 doc 12 安全约束：不指示忽略来源、不诱导编造

### 2.2 新增 Celery 任务
- **文件**：`services/ai-orchestrator/orchestrator/tasks.py`
- **新增**：`generate_docs()` 任务，注册名 `orchestrator.generate_docs`
- **执行流程**：
  1. 加载项目架构（优先 published，fallback draft）
  2. 加载所有已解析的 AssetChunk
  3. 删除已有 draft 文档（幂等性）
  4. 遍历非 category 节点，逐个调用 LLM 生成文档
  5. 写入 KnowledgeDoc + KnowledgeDocVersion + SourceRef
  6. 检测冲突时创建 ConflictRecord
  7. 更新 Job 状态

### 2.3 API 调度集成
- **文件**：`services/api/app/services/job_service.py`
- **修改**：新增 `kb_generate` → `orchestrator.generate_docs` 调度分支
- **影响**：仅新增 elif 分支，不改动已有 `ingest` 和 `architecture_draft` 逻辑

### 2.4 新增测试
- **文件**：`services/ai-orchestrator/tests/test_prompts.py` — 新增 6 个测试
- **文件**：`services/ai-orchestrator/tests/test_generate_docs.py` — 新建 10 个测试
