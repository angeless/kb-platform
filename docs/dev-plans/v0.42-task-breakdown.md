## 拆解约束

1. **不超出 dev-plan-v0.42.md 设计边界** — 不引入计划中"明确不做"的能力
2. **不随意重构代码** — 仅修改任务直接涉及的文件
3. **不修改原有业务逻辑** — 现有接口行为不变，除非计划明确要求修改
4. **每个子任务可独立提交** — 一个 commit 对应一个子任务
5. **每个子任务有明确验收标准** — 可通过具体操作验证通过/不通过
