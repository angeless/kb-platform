CRITICAL SEVERITY
================================================================================

[1] IDOR: Cross-Tenant Node Assignment (CWE-639)
File: services/api/app/services/doc_service.py:86-103
Issue: assign_node() method does not verify target architecture node belongs
       to same project/tenant. Allows assigning documents to another tenant's
       nodes, leaking cross-tenant data via foreign keys.
Status: REQUIRES IMMEDIATE FIX
Remediation: Add Architecture.project_id == doc.project_id check before
             assignment. See SECURITY_REMEDIATION_GUIDE.md Section 1.

================================================================================
HIGH SEVERITY
================================================================================

[2] Authentication Bypass: Rate Limiter Accepts Expired Tokens (CWE-613)
File: services/api/app/middleware/rate_limit.py:50-69
Issue: Rate limiter extracts tenant_id from JWT tokens with
       options={"verify_exp": False}. Allows expired tokens to bypass
       rate limiting and cause DoS against specific tenants.
Status: REQUIRES FIX
Remediation: Enable token expiration verification. Fallback to IP-based
             rate limiting for expired tokens. See SECURITY_REMEDIATION_GUIDE.md
             Section 2.

[3] DoS: Rate Limiter Fails Open (CWE-693)
File: services/api/app/middleware/rate_limit.py:78-81, 130-133
Issue: When Redis is unavailable, rate limiter allows all requests through
       with no fallback protection. Exposes system to brute force and DoS.
Status: REQUIRES FIX
Remediation: Implement in-memory rate limiter fallback or circuit breaker.
             Fail to fallback instead of failing open. See
             SECURITY_REMEDIATION_GUIDE.md Section 3.

================================================================================
MEDIUM SEVERITY
================================================================================

[4] SSRF: Missing Localhost Alias in Blocklist (CWE-918)
File: services/api/app/utils/url_fetcher.py:20-29
Issue: IP blocklist missing 0.0.0.0 (IPv4 any) and :: (IPv6 any) which can
       be used as localhost aliases to bypass SSRF protection.
Status: EASY FIX
Remediation: Add ipaddress.ip_network("0.0.0.0/32") and
             ipaddress.ip_network("::/128") to _BLOCKED_NETWORKS.
             See SECURITY_REMEDIATION_GUIDE.md Section 4.

[5] ZIP Bomb: Missing Decompression Size Limits (CWE-409)
File: services/api/app/services/asset_service.py:153-247
Issue: import_archive() checks file count and path traversal but not
       decompressed size. Allows ZIP bomb attacks causing memory/disk
       exhaustion.
Status: REQUIRES FIX
Remediation: Check ZipInfo.file_size before decompression. Enforce limits:
             500 MB per file, 2 GB total. See SECURITY_REMEDIATION_GUIDE.md
             Section 5.

[6] Crypto: Weak Key Derivation (CWE-326)
File: services/api/app/utils/crypto.py:8-13
Issue: _derive_key() pads with zeros and provides no key stretching.
       Encrypted API keys vulnerable to brute force. Need PBKDF2 or similar.
Status: REQUIRES FIX
Remediation: Replace with PBKDF2 (100k iterations, SHA256). Maintain
             backward compatibility for existing encrypted data. Add migration
             script. See SECURITY_REMEDIATION_GUIDE.md Section 6.
